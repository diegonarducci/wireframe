# Sidemed Wireframe

Protótipo navegável em React + Vite + Tailwind, pronto para deploy na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal, normalmente:

```bash
http://localhost:5173
```

## Build local

```bash
npm run build
npm run preview
```

## Deploy na Vercel

1. Suba este projeto para um repositório no GitHub.
2. Acesse a Vercel e clique em **Add New Project**.
3. Selecione o repositório.
4. Framework Preset: **Vite**.
5. Build Command: `npm run build`.
6. Output Directory: `dist`.
7. Clique em **Deploy**.

## Estrutura

```txt
sidemed-wireframe/
  index.html
  package.json
  vite.config.js
  src/
    App.jsx
    index.css
    main.jsx
```
